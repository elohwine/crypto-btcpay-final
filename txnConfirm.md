 here are the **exact fields** you should check to consider a TRC20 (USDT) transaction *confirmed and valid*, plus a small TypeScript validation snippet you can drop into your webhook/worker.---## ✅ Minimal canonical checks (required)Use these fields first — they prove the tx was mined and executed:1. **`confirmed: true`**   * Means the node/tronscan considers the tx included in a block.2. **`contractRet: "SUCCESS"`**   * Means the contract call (TRC20 `transfer`) executed successfully.3. **`block`** (or `blockNumber`) **exists and > 0**   * The transaction was included in block `block`. Use this together with `confirmations`.4. **`confirmations`** (numeric)   * Number of confirmations. Decide your safety threshold (e.g. `>= 1` for immediate, `>= 20` for high confidence). Make it configurable.---## ✅ Token-specific correctness checks (strongly recommended)Match these to the expected payment details (from your invoice/payment record):5. **`trc20TransferInfo[0].contract_address`**   * Must equal the token contract you expected (USDT TRC20 contract on that network / testnet).6. **`trc20TransferInfo[0].to_address`**   * Must equal the recipient/store wallet you expect.7. **`trc20TransferInfo[0].from_address`** (optional)   * Can be used to confirm the sender.8. **`trc20TransferInfo[0].amount_str`** (string integer in token's smallest unit)   * Must equal the expected amount (watch decimals — `decimals` field tells you).9. **`trc20TransferInfo[0].decimals`**   * Use to convert `amount_str` to human-readable amount.---## ✅ Additional safety checks (optional but useful)10. **`event_count` > 0** or **`trc20TransferInfo` length > 0** — events were emitted.11. **`revert: false`** — tx did not revert.12. **`tokenTransferInfo`** — sometimes duplicate/normalized info; cross-check with `trc20TransferInfo`.13. **`contract_map[contract_address] === true`** — indicates contract recognized (not required but helpful).14. **`srConfirmList` length** — shows block witnesses; not required for standard confirmation.15. **`cost`** fields if you want to audit fees/energy.---## Suggested confirmation policy (example)* Mark transaction **PENDING** until:  * `confirmed === true`  * `contractRet === "SUCCESS"`  * `trc20TransferInfo` exists and `to_address` & `amount_str` match expected  * `confirmations >= requiredConfirmations` (configurable; e.g. `requiredConfirmations = 20`)* Then mark **CONFIRMED** and credit the user.---## TypeScript validation snippet (Axios)Drop this into your webhook handler or background verifier. Adjust `requiredConfirmations`, expected contract, to/from amounts as needed.```tsimport axios from 'axios';type TxInfo = any; // replace with your typed interface if you wantasync function validateTrc20Tx(txHash: string, expectations: {  expectedContract: string,  expectedTo: string,  expectedAmountBaseUnits: string, // amount as integer string in token base units  requiredConfirmations?: number}) {  const requiredConfirmations = expectations.requiredConfirmations ?? 20;  const url = `https://shastapi.tronscan.org/api/transaction-info?hash=${txHash}`;  const resp = await axios.get<TxInfo>(url);  const tx = resp.data;  // Basic mined + executed checks  if (!tx || tx.confirmed !== true) throw new Error('Transaction not confirmed on-chain');  if ((tx.contractRet || '').toUpperCase() !== 'SUCCESS') throw new Error('Contract execution not successful');  // Confirm confirmations threshold  if (typeof tx.confirmations === 'number' && tx.confirmations < requiredConfirmations) {    throw new Error(`Insufficient confirmations: ${tx.confirmations} (< ${requiredConfirmations})`);  }  // Find trc20 transfer info (first matching event)  const tinfo = (tx.trc20TransferInfo && tx.trc20TransferInfo[0]) || tx.tokenTransferInfo || null;  if (!tinfo) throw new Error('No TRC20 transfer info found');  // Validate contract, to address, amount  if ((tinfo.contract_address || '').toUpperCase() !== expectations.expectedContract.toUpperCase()) {    throw new Error('Token contract mismatch');  }  if ((tinfo.to_address || '') !== expectations.expectedTo) {    throw new Error('Recipient address mismatch');  }  if ((tinfo.amount_str || '') !== expectations.expectedAmountBaseUnits) {    throw new Error('Amount mismatch');  }  // Optional: check revert flag  if (tx.revert === true) throw new Error('Transaction reverted');  // Passed all checks  return {    ok: true,    block: tx.block,    confirmations: tx.confirmations,    contractRet: tx.contractRet  };}```**Usage example:**```tsawait validateTrc20Tx('a7d5a2ac5e3f...', {  expectedContract: 'TQwXRK7EqDitMDhHNnTKPGpT9ZohJUxe3q',  expectedTo: 'TQK3DrqthcDJNdMZGmBXDLMznGqa72pcLG',  expectedAmountBaseUnits: '10000000', // 10,000,000 (6 decimals -> 10 USDT)  requiredConfirmations: 5});```---## Short checklist to implement now* Check `confirmed === true` and `contractRet === "SUCCESS"`.* Verify `trc20TransferInfo[0].contract_address`, `to_address`, and `amount_str` match expected values.* Require `confirmations >= N` (configurable).* Optionally ensure `revert === false` and `event_count > 0`.---
